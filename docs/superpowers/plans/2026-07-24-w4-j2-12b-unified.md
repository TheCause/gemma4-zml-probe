# W4 — Jalon J2 : Gemma 4 12B Unified w4a16 sur la 3090 — Plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Le 12B (`Gemma4UnifiedForConditionalGeneration`, checkpoint officiel `google/gemma-4-12B-it-qat-w4a16-ct`) décode sur la 3090 en ZML, gates U0→U10 PASS : décode court **48/48 == HF-même-checkpoint** (oracle CPU M4/VM — la voie GPU-HF est morte, cf Amendement), décode long **1150/1150 == HF teacher-forcé** + fenêtre 1024 prouvée mordante in-process, moteur E2B **préservé par preuve HLO byte-identique** (gate U1).

**Architecture:** Deux mouvements. (1) `engine.zig` acquiert une **géométrie comptime `Geom`** (défauts = valeurs E2B actuelles, alias publics conservés avec leurs types) — neutralité prouvée par md5 HLO `before_optimizations` (méthode T0/S1) + témoins `gemma4_gen_auto` ET `gemma4_w4auto` re-PASS. (2) Le runner 12B (`g12.zig` + `gemma4_g12auto`) reprend le pattern W4Step de J1 : poids packés chargés via `TensorStore`, `dequantW4` **réutilisée telle quelle** (shape-générique, prouvée J1), assemblage par valeur d'un `EngineModel` instancié `Geom.g12`, `forwardStep` inchangé. Oracles Python par tranches (`safe_open`, hooks sur modules réels), décode 48 tokens + prefill teacher-forcé long contre HF CPU (**M4 32 Gio = plan A**, VM = repli).

**Tech Stack:** ZML (workspace VM `adee932e`, patch pjrt en place), Zig/Bazel, Python : venv **NEUF `g12b`** (transformers ≥ 5.10.1 + compressed-tensors — 5.9.0 ne connaît pas `model_type: gemma4_unified` ; tous les scripts 62-70 tournent dans g12b) sur la VM ET sur M4 (M4 : sans compressed-tensors, il ne lit que l'export dense).

**Spec:** `docs/superpowers/specs/2026-07-18-w4-poids-4bit-12b-design.md` (jalon J2). La carte des diffs §4.2 de la spec est **corrigée par la cartographie du 24 juil** (D1 ci-dessous) : les couches full sont MQA 1×512 K=V, pas GQA 16/8. Un erratum sera posé dans la spec en Task 11.
